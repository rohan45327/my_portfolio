Jarvis – AI-Powered Personal Voice Assistant

Jarvis is a Python-based intelligent assistant capable of answering almost anything through both voice and text inputs. Users can interact via microphone commands or directly through the keyboard, making it flexible and accessible.

Key Features:
🎤 Dual Input Modes – Accepts queries from microphone (voice) or keyboard (text).
🧠 Answer Anything – Handles general knowledge, reasoning, problem-solving, and user-specific queries.
📚 Persistent Memory – Remembers past interactions and preferences for a more personalized experience.
🌐 Live Integrations – Fetches weather, news, jokes, and other data from APIs.
⚡ Automation Support – Can open apps, websites, play music, and perform routine tasks.
🛠️ Expandable Design – Built with modular Python logic for easy upgrades and new features.

This project reflects my ability to combine Python, speech recognition, text processing, and API handling into a powerful assistant that feels interactive, adaptive, and real-world ready.
